# Demonstration captures

These are unedited PNG captures of the signed Mosslight Studio 0.1.0 release running in an isolated Android API 36 emulator at 1080×2160, 420 dpi, with normal text size.

- `room.png`: the initial six-piece conservatory and movement controls.
- `arrange.png`: a fern preview moved one column using the coordinate control, before committing it.
- `print.png`: a pattern assembled through the app's leaf, star, and drop controls. It is the same composition the PNG exporter renders.

The screens contain synthetic project content and generic Android status/navigation chrome. System typefaces are rendered by Android; no font files are bundled. The files contain only PNG image chunks, with no EXIF, location, author, or text metadata. They demonstrate actual output, not a design mockup or physical-device test.

Follow the three-step walkthrough in the root README to reproduce the experience. Use the installable release to inspect movement, placement feedback, persistence, and the Android share chooser.
